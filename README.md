# Investment

持仓手记：用于记录股票、ETF 每笔买入价格、数量和卖出配对的自用安卓 App，使用 React Native / Expo SDK 58，可在 Expo Go 中运行。

## 已完成的功能

- 逐笔买入、部分卖出、指定买入批次或先进先出配对。
- 买入批次卡片、按买入价汇总剩余持仓、交易流水、编辑与删除。
- 本地自动保存、演示账本、完整 JSON 备份、CSV 流水导出。
- 导入旧网页版 JSON 或 UTF-8 CSV / TSV；重复检测和导入预览。
- 安卓系统目录选择与文件分享。数据只在设备本地，不上传真实成交。
- 简化首页和表单；新交易默认 100 股，数量右侧按钮每次增减 100。
- 根据价格、数量、买卖方向、证券类别和日期自动估算交易费用，可展开明细或手动修改。

## 费用计算（2026-11-09 核对）

按用户确认的账户费率：**全佣万一，单笔最低 0.50 元**。这里的费率基数是成交金额（价格 × 数量），经手费和证管费已包含在全佣内，不重复收取。

- 普通 A 股：买卖均计算成交金额 × 0.001% 的过户费；卖出另算印花税。2023-08-28 起为 0.05%，此前为 0.1%。
- 场内 ETF / 基金：按同一自用佣金配置估算，不加股票印花税、过户费。
- 每项先四舍五入到分再相加。例如 A 股 10 元 × 100 股，买入费用 0.51 元，卖出费用 1.01 元。
- 自动计算覆盖 2022-04-29 起的记录。更早日期、未识别品种（如港股、可转债、存托凭证）需手动填写费用，不套用普通 A 股税费。
- 常见沪深股票、基金代码自动识别；可在「明细」里修改类别。数量可以直接输入零股，减号不会减到零或负数；指定持仓不足 100 股时默认填入剩余数量。
- 现有 / 导入记录的费用保持原值，编辑时点击「恢复自动」才按此配置重算。手动修改的费用不会随价格、数量变化被覆盖。保存的是当笔实际采用的总费用，不会因以后规则更新而重算旧账。
- 券商可能把过户费也合并进佣金，或采用不同舍入/最低计费方式；此时可按交割单手动改费用总额。上述 0.50 元起收是用户指定配置，不代表所有券商统一标准。

核对来源：[券商费用项目与基金差异](https://www.crsec.com.cn/business/standard.html)、[税务总局 2023 年印花税减半公告](https://guangxi.chinatax.gov.cn/xxgk/zfxxgk_22500/fdzdgknr/zcfg_22514/zcwj_22515/202308/t20230828_391025.html)、[上交所费用表](https://www.sse.com.cn/services/tradingservice/charge/ssecharge/)。

## 在安卓 Expo Go 中打开

1. 在手机上安装与 **SDK 58** 对应的 Expo Go：<https://expo.dev/go>。
2. 手机与电脑连接同一 Wi-Fi。
3. 双击本目录中的 `启动手机预览.command`，或在终端运行：

```sh
git clone https://github.com/MQinghe/Investment.git
cd Investment
npm ci
npm start -- --lan --port 8082
```

4. 用 Expo Go 扫描终端显示的二维码。

这属于开发预览，电脑与服务需要保持运行。网络或地址改变后，请扫描新的二维码，不要继续使用旧二维码。

## 不在同一 Wi-Fi 时

双击 `启动公网手机预览.command` 或运行 `npm run tunnel`。这会使用 Expo 支持的 ngrok 隧道，不需要手机能访问电脑的局域网。

启动后以终端最新的 `.exp.direct` 地址为准。Expo Go 支持用 `exps://` 连接 HTTPS，可将终端地址的 `exp://` 改为 `exps://` 后手动输入。隧道停止或重启后旧地址可能失效；电脑和开发服务仍需保持运行。

SDK 58 的默认 Expo 公网隧道需要登录 Expo 账户，也可选择：

```sh
npx expo login
npm run tunnel:expo
```

登录请在终端或官方登录网页中完成，不要在聊天中发送密码、验证码或访问令牌。

GitHub 仓库提供源码；手机预览仍依赖正在运行的 Expo 开发服务，尚未配置独立 APK 或长期在线发布。

## 本地数据

AsyncStorage 键为 `@grid-journal/mobile/v1`。卸载 Expo Go、清除应用数据或切换项目可能无法继续读取原账本。请定期导出 JSON 并保留备份。

JSON 格式与旧网页版一致：`app: grid-ledger`、`version: 1`。手机端 CSV 仅接受 UTF-8，其他编码请先在表格软件中另存为 UTF-8。所有金额为人民币，未处理实时行情、分红、拆合股、外币或融资融券。
